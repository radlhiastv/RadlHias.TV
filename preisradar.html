Was ist dein Gebrauchtrad noch wert?

Verkaufen ohne Bauchgefühl: Trag dein Rad einmal sauber ein, und du bekommst einen realistischen Richtpreis samt Verhandlungsspanne – berechnet aus vergleichbaren Angeboten derselben Marke, Kategorie und Ausstattung.

Wichtig zur Einordnung: Die hinterlegte Vergleichsdatenbank ist noch ein Beispieldatensatz und keine vollständig recherchierte Marktübersicht. Das Tool zeigt dir, wie sich ein Gebrauchtpreis zusammensetzt und in welchem Korridor du ungefähr landest – es ersetzt keine Bewertung durch mich oder deinen Händler. Besonders bei hochwertigen Rädern über etwa 2.000 € liegen die Zahlen tendenziell zu niedrig.

Für Profis: eigene Vergleichsdaten laden

Du hast eigene Marktdaten recherchiert? Lade sie hier als CSV hoch – sie ersetzen die eingebaute Datenbank für diese Sitzung. Nichts wird hochgeladen oder gespeichert, die Auswertung passiert komplett in deinem Browser.

Erwartetes Format (Kopfzeile exakt so):

hersteller,modell,kategorie,baujahr,zustand,schaltung_typ,schaltgruppe,bremsen,schutzbleche,beleuchtung,rahmenmaterial,gewicht,motor_hersteller,akkukapazitaet,sonderausstattung,preis,portal,datum,status

Feld-Erklärung:

kategorie: trekking / citybike / mtb / rennrad / gravel / ebike_trekking / ebike_mtb / ebike_city / kinderrad / lastenrad
zustand: 1–5 (1 = stark gebraucht, 5 = neuwertig) – gleiche Skala wie im Formular
schaltung_typ: kette / nabe / keine
schaltgruppe: optional, nur relevant bei schaltung_typ = kette oder nabe. Bei Kette: unbekannt / tourney / altus / acera / alivio / deore / slx / xt / xtr / rennrad_einstieg / rennrad_mitte / rennrad_ober / sram_andere. Bei Nabe: unbekannt / shimano_7 / shimano_8 / shimano_11 / rohloff / andere. Leer lassen oder "unbekannt" eintragen, wenn nicht recherchiert.
bremsen: scheibe_hydraulisch / scheibe_mechanisch / felge / ruecktritt
schutzbleche: ja / nein    beleuchtung: fest / steck / nein
preis: Angebotspreis in Euro (Zahl, ohne Symbol)    status: aktiv / verkauft (falls bekannt)
portal: z.B. willhaben, kleinanzeigen, ebay ...    datum: Datum des Angebots (YYYY-MM-DD)
gewicht: optional, in kg (Zahl, z.B. 14.5). Leer lassen wenn unbekannt.
rahmenmaterial: aluminium / carbon / stahl / titan / unbekannt
motor_hersteller: bosch / shimano / bafang / brose / yamaha / andere / kein (kein = kein E-Bike)
akkukapazitaet: optional, in Wh (Zahl, z.B. 500). Nur bei E-Bikes relevant, sonst leer lassen.
